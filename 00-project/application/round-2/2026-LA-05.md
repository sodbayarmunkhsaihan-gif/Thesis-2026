# Language Learning Assistant with Individual Progress Tracking

## My interpretation of the brief

The project is a database-centered language learning assistant for English. The system stores learning items, users, practice sessions, answers, and results. Based on previous performance, the database recommends which items the student should practise next.

## Why I am a good fit for this project

I am interested in language learning and database systems. I also think the project is closely related to my university studies because it focuses strongly on relational database design and SQL. The project has a clear structure, while still giving me an opportunity to improve my practical skills.

## Relevant experience and background

I have basic programming, database, and SQL knowledge from my studies. I am still developing my practical experience with stored procedures, database optimization, and large datasets. I am willing to learn these areas during the project.

## Proposed approach

I would design a relational database containing users, learning items, topics, practice sessions, answers, and results. The database would store the student's previous performance and use stored procedures or functions to calculate the priority of learning items. The application would receive the recommended practice sequence directly from the database.

## Initial plan

I would first design the database structure and relationships. Then I would implement the practice and progress tracking logic. I would create at least two different selection strategies and compare their results. I would also generate a larger test dataset, create the required SQL queries, and measure query performance before and after optimization.

## Additional information

I would keep the user interface simple and focus mainly on the database logic. My main goal would be to create a clear, reliable, and well-tested system while improving my practical database skills.
