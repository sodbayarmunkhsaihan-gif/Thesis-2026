# Receipt-based Shared Expense Allocation Application

## My interpretation of the brief

The project is a mobile and web application for managing shared expenses from receipts. Users can upload or photograph a receipt, review the recognized items, choose the payer and participants, and divide the expenses. The system should support different allocation methods such as equal, percentage, and fixed-amount splits.

## Why I am a good fit for this project

I am interested in practical applications that combine databases, web development, and AI. I also think this project is useful because splitting expenses from receipts is a common everyday problem. The project would allow me to improve my programming and database skills while learning how AI can be used in a real application.

## Relevant experience and background

I have basic knowledge of programming, databases, SQL, and web development from my university studies. I do not have extensive experience with OCR or LLM-based processing yet, but I am interested in learning these technologies during the project.

## Proposed approach

I would first design the database and define the main application workflow. The system would use OCR and AI to suggest receipt information, while the user would be able to review and correct the results. The financial calculations, allocation rules, rounding, and balances would be handled by deterministic application logic rather than relying on the AI.

## Initial plan

First, I would define the main users, data, and workflow. Then I would design the relational database and implement receipt upload and item recognition. After that, I would implement expense allocation, calculations, approval, and balance tracking. Finally, I would create a simple web/mobile interface and test the system with different receipt and expense scenarios.

## Additional information

I would focus on the required features first and keep the first version simple. I would also document the AI limitations and make sure that incorrect AI suggestions can be reviewed and corrected by the user.
